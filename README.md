# rutils

Development tool

# Build
```shell

cargo build --release
```

# How to use?
+ add an environment variables to exec binary
+ typing `cz tf 1734477030007`
+ typing `cz now` or `rutils now -l`
+ typing `cz jf`, then paste JSON with spaces at the prompt and press Enter (no shell quoting or escaping needed)
+ `jf` colors keys, strings, numbers, and boolean/null values in terminal output; color is disabled when output is redirected or `NO_COLOR` is set
